# ReFlo+

A touch-first Bluetooth mixer control app by DevCrest.

ReFlo+ is being released on the **Apple App Store** and **Google Play**. Search for "ReFlo+" in either store.

Earlier free downloads and sideload packages that were published on this page have been withdrawn. Please get the app from the stores.

## Privacy

ReFlo+ does not collect, send, sell or share any personal data. It has no accounts, no analytics, no advertising and no internet access.

Full policy: **[Privacy Policy](privacy)**

## Disclaimer

ReFlo+ is an independent app, not made, endorsed or supported by any mixer manufacturer. It sends live control commands to a mixer (levels, phantom power, routing). Check settings before use and keep headphone levels safe.
